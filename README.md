# Specify — Landing Page

A modern, responsive landing page created to present the Specify project through a clear layout and user-focused interface.

## Live Demo

[View the deployed landing page](https://specify-6u4ivzpkj-youssefalhares2-5045s-projects.vercel.app/)

## Features

- Responsive layout for desktop and mobile screens.
- Clean visual hierarchy and page sections.
- Reusable styling with CSS and SCSS.
- Lightweight front-end implementation.

## Built With

- HTML5
- CSS3
- SCSS
- JavaScript

## Getting Started

Clone the repository:

```bash
git clone https://github.com/youssefibrahimahmed/Specify.git
cd Specify
```

Open `index.html` in your browser, or use the Live Server extension in VS Code.
